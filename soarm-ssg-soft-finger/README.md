# SO-ARM SSG Soft Finger

This folder contains STL files for a SO-ARM gripper finger concept based on the SSG-style soft/fin-ray finger approach.

## Files

- `RB9.01.062_1.stl`
- `RB9.01.062_2.stl`

## Notes

- The design direction is to keep the SO-ARM parallel gripper mounting interface.
- The finger shape is intended to reference the SSG-style soft/adaptive finger concept.
- These STL files are for 3D model sharing and fabrication review.
