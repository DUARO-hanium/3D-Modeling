# SO-ARM SSG Soft Finger

이 폴더는 SO-ARM parallel gripper에 장착하기 위한 SSG-style soft finger STL 파일을 정리한 공간입니다.

## 파일

- `RB9.01.062_1.stl`
- `RB9.01.062_2.stl`

## 설계 방향

- SO-ARM 기존 parallel gripper의 장착 구조를 유지합니다.
- SSG-48 전체 그리퍼를 사용하는 것이 아니라, SSG-style soft/adaptive finger 형상을 참고합니다.
- 물체와 접촉하는 finger 부분을 개선하여 파지 안정성과 형상 대응성을 높이는 것을 목표로 합니다.
- 이 STL 파일들은 3D 모델 공유와 출력 검토를 위한 파일입니다.
